# Contributing to Mycelic

## Setup

```bash
git clone https://github.com/PNurmanM/MycelicLabs.git
cd MycelicLabs
cargo build --release                                  # Rust 1.88+ (rustup.rs)
```

The research code under `research/` is Python: `python3 -m venv .venv && pip install -r requirements.txt`.

## Tests

```bash
cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace                                   # unit, golden, API, MCP; JetStream + process tests need nats-server
./target/release/mycelic-smoke --driver process          # the production smoke test against local processes
./target/release/mycelic-smoke --driver compose          # the deployment test (builds the image)
python -m unittest research.mycelic.test_mycelic         # the research code
```

The integration tests run a real `nats-server` when `MYCELIC_NATS_SERVER_BIN` (or `nats-server` on `PATH`) is
available and skip themselves otherwise. Run the compose smoke test before changing anything under
`deploy/mycelic/`.

## Where code goes

- **Server** (`crates/mycelic`): the service, its HTTP API, MCP and the `mycelic` CLI.
- **Agent side** (`crates/mycelic-sdk`: the client, `LocalMemory` and `mycelic-agent`; `crates/mycelic-harness`:
  the drivers, the smoke test and the demos) never depends on the server crate, so an agent does not carry the
  service's stack (axum, rusqlite's server schema, async-nats). `crates/mycelic-harness/tests/layout.rs` enforces it
  from `cargo metadata`.
- **Behaviour is pinned to the original Python implementation** by the golden fixtures in
  `crates/mycelic/tests/golden/` (generated by the Python code at commit `ef2c52b`). A change that alters a
  derived id, a confidence, a response body or a stored JSON column is a compatibility break for existing
  deployments: change the fixture deliberately, in the same commit, and say why.
- **`coordination.rs`, `textutil.rs`, the MCP protocol core in `mcp.rs`** descend from code copied from
  [NeuralGraph](https://github.com/anovruzov/NeuralGraph) at `e7ef73ea`. They are Mycelic's code now: change them
  here as needed; nothing syncs them back.

## Research

`research/mycelic/README.md` has the commands that reproduce every number in
[`docs/MYCELIC_ENTERPRISE.md`](docs/MYCELIC_ENTERPRISE.md). Raw per-run rows belong in
`research/mycelic/artifacts/`; feature dumps are gitignored and regenerate.

## Style

Match the file you are editing. The codebase favours explicit names, docstrings that say *why* rather than
*what*, and comments only where the reason is not obvious from the code.
